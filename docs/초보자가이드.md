# LunchPicker 초보자 가이드

이 문서는 **시안(앱 화면 설계)** 기준으로  
“어디를 고치면 되는지”를 초보자도 따라갈 수 있게 정리한 지도입니다.

코드를 처음부터 다시 만들지 않습니다.  
이미 있는 기능을 살리고, **화면을 하나씩** 시안에 맞춰 갑니다.

---

## 1. 프로젝트를 여는 방법

터미널에서:

```bash
npm install
npm run dev
```

브라우저에 나온 주소(보통 `http://localhost:5173`)로 확인합니다.

문제가 생기면:

```bash
npm run build
```

으로 오류 메시지를 먼저 확인합니다.

---

## 2. 폴더만 보면 되는 규칙

| 폴더 | 한 줄 설명 | 언제 열까? |
|------|------------|------------|
| `src/views/` | **페이지 전체** (홈, 식당 목록 등) | 새 화면을 만들 때 |
| `src/components/` | **페이지 안의 조각** (버튼, 카드, 히어로) | 버튼·카드 디자인만 바꿀 때 |
| `src/composables/` | **동작 로직** (랜덤 뽑기, 필터) | “어떻게 뽑히는지”를 바꿀 때 |
| `src/services/` | **데이터 가져오기** (지금은 mock) | 식당 목록 API/DB 연결할 때 |
| `src/data/` | **가짜 식당 데이터** | 테스트용 식당을 추가할 때 |
| `src/styles/variables.css` | **색·간격 공통 값** | 메인 컬러 `#FF8A00` 등 |
| `src/router/index.js` | **주소 ↔ 페이지 연결** | `/history` 같은 경로 추가할 때 |

기억할 것 하나만:

> **화면(view)은 조립만 하고, 복잡한 계산은 composable에 둔다.**

## 3. 시안 화면 ↔ 파일 지도

| 시안 화면 | 상태 | 주로 수정할 파일 |
|-----------|------|------------------|
| 홈 (Hero + 빠른 조건) | ✅ 있음 (Hero 시안 레이아웃 반영) | `views/HomeView.vue`, `components/home/HomeBrand.vue`, `components/home/QuickFilters.vue` |
| 하단 탭 | ✅ 골격 있음 | `components/layout/AppBottomNav.vue`, `layouts/DefaultLayout.vue` |
| 식당 목록 | ✅ 시안 카드 UI | `views/RestaurantsView.vue`, `components/lunch/RestaurantCard.vue`, `composables/useWishlist.js` |
| 식당 상세 | ✅ 있음 | `views/RestaurantDetailView.vue` (카드 클릭, 직접등록만 삭제) |
| 조건 설정 (전체 화면) | ✅ 있음 | `views/FiltersView.vue` (홈 카드 → `/filters`) |
| 뽑기 결과 (축하 화면) | ✅ 있음 | `views/PickResultView.vue`, `components/lunch/PickResult.vue` |
| 히스토리 | ✅ 있음 | `views/HistoryView.vue`, `composables/usePickHistory.js` |
| 설정 | ✅ 있음 | `views/SettingsView.vue` |
| 맛집 등록 (+) | ✅ 있음 | `views/AddRestaurantView.vue`, `services/restaurantService.js` |

## 4. 앞으로 작업 순서 (이것만 지키면 됨)

한 번에 전부 만들지 마세요. 아래 순서를 권장합니다.

1. **앱 껍질** — 하단 탭으로 화면 이동 ✅
2. **홈 다듬기** — Hero·필터를 시안에 더 가깝게 ✅
3. **조건 설정** — 필터 전용 화면 ✅
4. **뽑기 결과** — 풀스크린 추천 결과 ✅
5. **식당 목록** — 이모지·하트 등 카드 UI ✅
6. **히스토리 / 설정 / 등록** — 나머지 기능 ✅

Cursor(또는 다른 AI)에게 시킬 때도 이렇게 짧게:

> “시안 기준으로 **홈 Hero만** 좌우 레이아웃으로 맞춰줘. 다른 화면은 건드리지 마.”

## 5. “이것만 고치고 싶을 때” 빠른 찾기

### 메인 오렌지 색
→ `src/styles/variables.css` 의 `--color-brand`

### 홈 큰 오렌지 카드 (오늘 뭐 먹지?)
→ `src/components/home/HomeBrand.vue`

### 거리·메뉴·가격·인원 카드 (홈 요약)
→ `src/components/home/QuickFilters.vue`

### 조건 설정 전체 화면
→ `src/views/FiltersView.vue`

### 점심 랜덤 뽑기 로직
→ `src/composables/useLunchPick.js`

### 뽑기 결과 화면
→ `src/views/PickResultView.vue` / `src/components/lunch/PickResult.vue`

### 필터 선택값·옵션 목록
→ `src/composables/useQuickFilters.js`

### 가짜 식당 추가
→ `src/data/mockRestaurants.js`

### 식당 목록 / 하트(찜)
→ `src/views/RestaurantsView.vue`  
→ `src/components/lunch/RestaurantCard.vue`  
→ `src/composables/useWishlist.js`

### 식당 상세 / 삭제
→ `src/views/RestaurantDetailView.vue`  
(+로 등록한 식당만 삭제 가능)

### 네이버 지도 링크
→ `src/utils/mapLinks.js`  
→ 상세의 “네이버 지도에서 보기” 버튼 (`RestaurantDetailView.vue`)

### 우리 팀 한줄 메모
→ `src/components/lunch/RestaurantNotes.vue`  
→ `src/services/restaurantNoteService.js`  
→ 임시 사용자: `src/data/mockUser.js`

### 히스토리 / 설정 / 맛집 등록
→ `src/views/HistoryView.vue`  
→ `src/views/SettingsView.vue`  
→ `src/views/AddRestaurantView.vue`  
→ `src/composables/usePickHistory.js`

### 하단 탭 메뉴 글자/링크
→ `src/components/layout/AppBottomNav.vue`

### 새 주소(페이지) 추가
→ `src/router/index.js` + `src/views/새이름View.vue`

## 6. 하면 안 되는 것 (초보자용)

- 부탁하지 않은 **패키지 설치** (`npm install 무언가`)
- 이미 되는 **뽑기/필터 기능 삭제**
- 같은 역할의 **컴포넌트 중복 생성**
- 한 번에 시안 **전 화면** 구현 요청

더 자세한 에이전트 규칙은 루트의 `AGENTS.md`를 보면 됩니다.

## 7. 시안 기준 1~6단계

초보자가이드의 작업 순서 1~6은 모두 반영된 상태입니다.  
이제부터는 화면을 **하나씩** 다듬거나, Supabase 연결을 준비하면 됩니다.
